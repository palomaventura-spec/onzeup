ONZEUP v1.4.4.2

ALTERACOES
- O sandbox nao preenche mais MERCADOPAGO_TEST_PAYER_EMAIL automaticamente.
- O e-mail do pagador passa a ser digitado no formulario.
- Nao use:
  1) o mesmo e-mail da sua conta Mercado Pago;
  2) e-mail de usuario de teste do Mercado Pago.
- Backend grava apenas flags seguras:
  accessTokenIsTest true/false
  publicKeyIsTest true/false
  VERCEL_ENV
  NODE_ENV
- Nenhum token/chave e exibido nos logs.

OPCIONAL
Voce pode cadastrar no Vercel:
MERCADOPAGO_ACCOUNT_EMAIL = e-mail real da sua conta Mercado Pago

Assim o backend impede por engano esse e-mail.
Nao e obrigatorio.

MERCADOPAGO_TEST_PAYER_EMAIL
Pode permanecer no Vercel por enquanto, mas o formulario nao a usa automaticamente.
O backend apenas impede que esse e-mail seja usado no teste.

COMO APLICAR
Extraia este ZIP numa pasta separada e copie os 3 arquivos para o projeto,
OU extraia sobre o projeto substituindo os arquivos correspondentes.

Depois:
npx prisma validate
npm run build

Git:
git add .
git commit -m "ONZEUP v1.4.4.2 - fix Mercado Pago test payer email"
git push origin main

TESTE
No campo E-mail do pagador:
- use um e-mail comum;
- diferente da sua conta Mercado Pago;
- que nao seja uma conta Comprador/Vendedor teste do Mercado Pago.

Depois confira no Vercel:
MP_RUNTIME_ENV {
  accessTokenIsTest: true,
  publicKeyIsTest: true,
  vercelEnv: "production"
}
