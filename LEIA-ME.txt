ONZEUP v1.4.6.1

Corrige o erro 400 na criação do Checkout Asaas.

Causa:
A v1.4.6 alterou billingTypes de ["CREDIT_CARD"] para ["PIX","CREDIT_CARD"] no checkout RECURRENT.
O fluxo recorrente que já havia sido homologado no Sandbox funcionava com CREDIT_CARD.

Correção:
billingTypes: ["CREDIT_CARD"]
chargeTypes: ["RECURRENT"]

O texto continua "Assinatura mensal".
PIX poderá ser incluído depois por um fluxo próprio, sem quebrar o checkout recorrente já validado.

Depois:
npx prisma validate
npm run build
git add -A
git commit -m "ONZEUP v1.4.6.1 - fix Asaas recurring checkout"
git push origin main
