ONZEUP v1.4.7.3 - CLUB REDIRECT FIX

Problema:
O Asaas criava os checkouts com status 200, mas o navegador nao era enviado ao checkout.

Causa:
redirect(checkout.link) estava dentro de try/catch.
No Next.js, redirect() usa internamente a excecao NEXT_REDIRECT.
O catch capturava essa excecao e impedia o redirecionamento correto.

Correcao:
A criacao e gravacao do checkout permanecem dentro do try/catch.
O redirect(checkout.link) acontece somente depois do try/catch.

Nao altera:
- Prisma
- webhook
- precos
- planos
- Asaas API

Depois:
npm run build

Se passar:
git add -A
git commit -m "ONZEUP v1.4.7.3 - fix Club checkout redirect"
git push origin main
