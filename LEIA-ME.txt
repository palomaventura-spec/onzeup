ONZEUP v1.4.7.2 - CLUB BILLING UI

Objetivo:
Integrar a assinatura Club ao fluxo real da organização.

Inclui:
- card "Plano e assinatura" no dashboard;
- durante o período grátis, botão "Ver planos e assinar";
- plano ativo mostra nome, periodicidade e data do período atual;
- pagamento pendente mostra CTA para regularização;
- menu lateral recebe "Plano e assinatura";
- Configurações recebe atalho para /planos;
- remove o DemoBanner do painel Club.

Não altera o schema Prisma.
Não altera checkout nem webhook.

Depois de aplicar:
npx prisma validate
npx prisma generate
npm run build

Se passar:
git add -A
git commit -m "ONZEUP v1.4.7.2 - integrate Club billing UI"
git push origin main
