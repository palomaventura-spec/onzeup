ONZEUP v1.4.4 — MERCADO PAGO + VÍDEOS EDITÁVEIS

O QUE ENTRA
1. Player Premium R$29,90/mês via Assinaturas Mercado Pago.
2. Checkout criado pelo backend do ONZEUP.
3. Webhook em /api/mercadopago/webhook.
4. Validação HMAC SHA-256 da assinatura secreta.
5. Premium só é liberado após evento "payment" com status "approved".
6. Webhooks repetidos do mesmo payment_id não prorrogam o Premium novamente.
7. Renovação mensal aprovada estende premiumUntil.
8. Cancelamento/pausa da assinatura atualiza planStatus.
9. Vídeos agora podem ter título, descrição e destaque.
10. Formato antigo de vídeos (um link por linha) continua compatível.
11. Sem alteração do schema Prisma nesta versão.

VARIÁVEIS NECESSÁRIAS NO VERCEL
MERCADOPAGO_PUBLIC_KEY
MERCADOPAGO_ACCESS_TOKEN
MERCADOPAGO_WEBHOOK_SECRET
APP_URL=https://www.onzeup.com.br

OPCIONAL PARA SANDBOX
Se o Mercado Pago exigir um comprador de teste:
MERCADOPAGO_TEST_PAYER_EMAIL=<email de uma Conta de teste do Mercado Pago>

WEBHOOK JÁ CONFIGURADO
https://www.onzeup.com.br/api/mercadopago/webhook

EVENTOS
- Pagamentos (legacy)
- Planos e assinaturas

COMO APLICAR
1. Extraia este ZIP dentro de:
   C:\Users\User\Documents\onzeup
2. Confirme a substituição dos arquivos.
3. Rode:
   APLICAR_V144.cmd
4. Depois:
   npx prisma validate
   npm run build

SE PASSAR
git add .
git commit -m "ONZEUP v1.4.4 - Mercado Pago subscriptions and editable video titles"
git push origin main

TESTE
1. Entre como responsável.
2. Abra um Player Free.
3. Clique "Assinar Premium • Mercado Pago".
4. Faça o pagamento com dados de teste do Mercado Pago.
5. Volte ao ONZEUP.
6. Confira Webhooks no Mercado Pago.
7. O evento payment aprovado deve alterar o Player para PREMIUM.
8. Edite os vídeos e confira títulos no site público.

IMPORTANTE
- Não use cartão real com credenciais TEST.
- Não cole Access Token ou Webhook Secret em código/GitHub.
- Esta versão usa os campos existentes de Payment para manter compatibilidade e evitar migração de banco antes da auditoria Production Readiness.
