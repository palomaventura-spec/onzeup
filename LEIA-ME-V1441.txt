ONZEUP v1.4.4.1 — MERCADO PAGO SANDBOX FIX

OBJETIVO
Corrigir o teste de assinatura do Player Premium usando o fluxo sandbox oficial:
TEST Access Token + X-scope: stage + CardToken + status authorized.

IMPORTANTE ANTES DE TESTAR
Os três valores abaixo precisam pertencer à MESMA aplicação Mercado Pago:
- MERCADOPAGO_PUBLIC_KEY
- MERCADOPAGO_ACCESS_TOKEN
- MERCADOPAGO_WEBHOOK_SECRET

Como o WEBHOOK_SECRET foi trocado durante os testes anteriores, confirme agora o segredo da aplicação ORIGINAL "onze up", a mesma aplicação que fornece a Public Key TEST e o Access Token TEST.

No Mercado Pago:
Aplicação "onze up" → Webhooks → Assinatura secreta

No Vercel:
MERCADOPAGO_WEBHOOK_SECRET = segredo dessa mesma aplicação

Também mantenha:
MERCADOPAGO_TEST_PAYER_EMAIL = e-mail da conta Comprador teste
APP_URL = https://www.onzeup.com.br

TESTE DEPOIS DO DEPLOY
1. Entrar como responsável do Player teste.
2. Clicar Assinar Premium.
3. Deve abrir uma página ONZEUP "MERCADO PAGO • SANDBOX".
4. Usar SOMENTE cartão oficial de teste Mercado Pago.
5. Para cenário aprovado, usar os dados oficiais de teste.
6. A criação da assinatura deve retornar status authorized.
7. O webhook payment approved poderá chegar depois; a documentação informa que a primeira parcela pode ser cobrada em até aproximadamente uma hora.
8. Quando payment approved chegar, o webhook atual altera FREE → PREMIUM automaticamente.
